# Web Pública Nova

Repositorio reservado para el sitio web público institucional del ecosistema NOVA.

## Estado

En el inventario GitHub del 2026-11-23, este repositorio tenía tamaño 0 KB y su único commit visible era un README inicial. No se encontró implementación del sitio en esa rama. Por tanto, se considera **pendiente de reconstrucción**, no una web operativa.

## Alcance por definir y validar

- Identidad visual y contenido institucional aprobados.
- Arquitectura de páginas públicas y navegación.
- Accesibilidad, diseño adaptable, SEO y rendimiento.
- Integración con Nova Apps y enlaces oficiales.
- Políticas de privacidad, contacto y seguridad.
- Pipeline de despliegue y pruebas antes de publicar.

No duplicar el portal/catálogo de Nova Apps aquí: la web pública y la plataforma de aplicaciones deben mantener responsabilidades diferenciadas.
